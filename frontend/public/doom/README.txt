DOOM для игр на TV (работает полностью офлайн).

doom.js / doom.wasm — движок doomgeneric, собранный в WebAssembly (проект pi-doom, GPL-2.0; исходный код DOOM — id Software, GPL-2.0).
doom1.wad          — DOOM1.WAD shareware v1.9 (эпизод 1), разрешён id Software к свободному распространению.

Управление четырьмя стрелками: вверх/вниз — ходьба, влево/вправо — поворот, вверх+вниз одновременно — огонь.
Кнопка «использовать» (двери, переключатели) нажимается автоматически.
